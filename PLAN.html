1 Subscription & nạp tiền ✓ XONG

Gói thành viên, đăng ký, giao dịch nạp tiền (sandbox).

Backend

  • Chạy migration reference_code đang pending
  • PlanController (index public)
  • SubscriptionController: me / subscribe / cancel
  • PaymentController: tạo txn + confirm sandbox
  • SubscriptionService: tính ends_at theo billing_cycle, sinh mã chuyển khoản
  • Routes auth: GET /plans, /me/subscription, POST /subscriptions, /payments, /payments/{ref}/confirm

Frontend

  • Trang /goi-thanh-vien: list plans
  • Nút "Nạp VIP" → tạo txn → QR/mã chuyển khoản giả
  • Nút "Tôi đã thanh toán" → confirm
  • Badge VIP trên header, lưu trạng thái vào user store

2 Nạp VIP → coi độ phân giải cao gate quality

Lọc nguồn video theo plan.max_quality của user.

Backend

  • VideoStreamController::canStream + lọc source theo max_quality
  • Free → cap 480/720 · VIP → 1080/4K
  • Source vượt quyền → trả 403 requires_vip thay vì 404

Frontend

  • Dropdown chọn quality trong player
  • Option vượt mức → hiện khóa + CTA "Nâng VIP"

3 Thay đổi audio cho phim multi-audio

Mỗi audio = 1 video_source song ngữ (đơn giản, hợp schema hiện tại).

Backend

  • Migration: thêm audio_language_id + audio_label vào video_sources
  • MovieController::show trả audio_options group theo language
  • Transcode job: xuất thêm audio rendition (giai đoạn sau)

Frontend

  • Dropdown "Âm thanh" trong player
  • Đổi audio → reload hls source, giữ nguyên currentTime

Frontend

5 Bình luận phân cấp model sẵn

comments đã có parent_id + polymorphic commentable.

Backend

  • CommentController: index (tree 2 cấp), store (reply qua parent_id), destroy (soft delete), report
  • Polymorphic trên Movie / Episode
  • Routes: GET /movies/{movie}/comments (public), POST /comments + DELETE /comments/{id} (auth)

Frontend

  • Khu bình luận dưới player: cha → con
  • Ô reply inline, nút xóa của chủ comment
