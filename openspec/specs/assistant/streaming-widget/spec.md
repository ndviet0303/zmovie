## Purpose

Provides an always-accessible floating AI assistant widget that streams conversational movie recommendations using Server-Sent Events (SSE).

## Requirements

### Requirement: Floating AI Assistant Widget
The user interface SHALL render a persistent floating action button across storefront pages that toggles a compact conversational assistant drawer without navigating away from the current page.

#### Scenario: Opening the floating assistant widget
- **WHEN** a user clicks the floating assistant badge on any page
- **THEN** the system SHALL expand the glassmorphism assistant chat window showing previous message history

#### Scenario: Minimizing the widget
- **WHEN** the user clicks the minimize or close icon on the assistant window
- **THEN** the chat drawer SHALL collapse back into the floating badge while maintaining conversation state in memory

### Requirement: Server-Sent Events Streaming Response
The assistant API SHALL stream generated response tokens sequentially over an HTTP text/event-stream connection instead of waiting for full generation completion.

#### Scenario: Streaming tokens during generation
- **WHEN** a user submits a query to the assistant
- **THEN** the system SHALL stream reply text chunks progressively as they are generated by the model, rendering a smooth typing effect with first token latency under 500ms

#### Scenario: Rendering structured title cards in stream
- **WHEN** the assistant references recommended catalog movies in its response
- **THEN** the widget SHALL display interactive title preview cards with poster, rating, and direct play links alongside the text
